# 공통 그레인 그라데이션과 제목 렌즈

기존 앱의 홈·제품 탐색·내 고민·내 제품·더보기·제품 상세·구매에 같은 배경을 적용합니다. 별도 랜딩 페이지는 없으며 이전 `?view=landing` 주소도 실제 홈으로 연결합니다. 메뉴, 제품 사진, 리뷰, 검색과 구매 흐름은 기존 앱을 사용합니다.

기본 테마는 다크입니다. HTML의 초기 테마와 스타일 로딩 전 스크립트가 첫 페인트부터 다크를 적용합니다. 사용자가 직접 저장한 라이트 선택은 유지하며, 토글 때 브라우저 테마 색과 네이티브 입력의 color-scheme도 함께 변경합니다.

## 화면 효과

- 흰색·검정·하늘색·파란색은 **배경 효과의 팔레트**입니다. 기존 UI 전체를 이 색으로 바꾸지 않습니다.
- 업로드한 15.55초 영상의 넓은 S자 색 띠와 검은 영역 이동을 참고했습니다. WebGL 풀스크린 쿼드와 GLSL로 화면 전체가 휘는 대각선 띠와 검은 로브를 그리며, 원본 영상의 주황색은 기존 파란색 계열로 바꿉니다. 마우스를 멈춰도 자동 흐름이 이어집니다.
- 포인터 위치가 화면 전체 색 띠의 기울기·곡률과 검은 영역의 위치를 바꿉니다. 빠르게 이동한 뒤에도 추종 위치와 잔상이 서로 다른 속도로 수렴해 관성이 남습니다. 기존 국소 밀어내기는 보조 효과입니다. 글자와 제품 사진을 밀거나 캡처하지 않습니다.
- 미세한 무채색 그레인은 화면 픽셀에 고정합니다. 홈 첫 화면과 빈 고민 검색 화면에는 넓은 명암을, 정보를 읽는 화면에는 기존 글자색에 맞는 낮은 강도를 사용합니다.
- 각 화면의 등록된 대표 제목에만 한국어→영어 원형 텍스트 렌즈를 적용합니다. 원 밖은 한국어 원문, 중심은 영어이며 굴절과 RGB 분리는 가장자리의 얇은 띠에 제한됩니다. 입력 문장·리뷰·사진은 텍스처로 만들지 않습니다.
- 터치 화면과 WebGL 미지원 환경에는 English↔한국어 제목 언어 전환 버튼을 제공합니다. 배경 Canvas는 링크·키보드 포커스·스크롤을 가로채지 않습니다.

모든 메뉴에서 배경 Canvas 하나를 재사용합니다. 제목 렌즈는 화면 변경 때 기존 GPU 자원을 해제한 뒤 새 제목에 연결합니다. 동작 줄이기에서는 배경을 정지하고, 비활성 브라우저 탭에서도 그리기를 중단합니다. WebGL 실패·컨텍스트 손실에서는 정적 CSS 그라데이션과 원래 HTML을 표시합니다. 투명도 감소·대비 증가·강제 색상 설정에는 명확한 단색 또는 시스템 배경을 사용합니다.

다크 모드의 보조 글자와 제품·리뷰·날짜·탭 메타데이터는 읽을 수 있는 밝기로 통일합니다. 내비게이션·카드·입력·대화상자는 중립적인 어두운 유리 바탕을 사용하고, 밝은 포스터 위 제목과 안내에는 별도 보호 그라데이션을 유지합니다.

## 설정과 파일

`site-effects-config.js` 한 곳에서 팔레트·시간·회전·변형·그레인·포인터 반경과 강도·보간 속도·렌즈 지름·문구를 조절합니다. `hero.ko`, `hero.en`, `hero.offsets`는 실제 홈의 세 줄 제목과 시작점을 정합니다. 기존 로고와 제품 이미지는 앱의 기존 자산 설정을 사용합니다.

| 파일 | 역할 |
| --- | --- |
| `site-effects-config.js` | 팔레트·동작·렌즈·문구 설정 |
| `site-background.js` | 배경 WebGL 쿼드·전역 곡률·검은 로브·그레인 |
| `ambient-background.js` | 전역 배경 생명주기·포인터 관성·테마·접근성 설정 |
| `site-text-effects.js` | 기존 화면 제목에 한국어·영어 레이어 연결 |
| `landing-text-lens.js`, `landing-lens-renderer.js` | 재사용하는 텍스트 마스크·가장자리 굴절 렌더러 |
| `site-effects.css` | 공통 배경·홈 타이포그래피·제목 레이어·대체 화면 |

이름에 `landing`이 남은 두 파일은 렌즈 엔진이며 별도 페이지나 라우트가 아닙니다. 레퍼런스의 사진·영상·폰트·소스 코드는 복제하지 않았습니다.

## 설치와 실행

Node.js 환경에서 실행합니다. 기존 Vite와 JavaScript 스택을 유지하며 런타임 그래픽 라이브러리를 추가하지 않았습니다.

```sh
npm ci
npm run dev
# http://localhost:5173/

npm run build
node --test --test-concurrency=1
```

실제 WebGL 픽셀 검증은 선택적으로 Playwright를 설치한 뒤 실행합니다. 앱 실행에는 필요하지 않습니다.

```sh
npm install --no-save playwright
npx playwright install chromium
npm run verify:effects
```

시스템 Chromium을 쓰려면 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/경로/chromium`을 지정합니다. 검증은 로컬 소스를 메모리에서 제공하므로 개발 서버나 외부 사이트가 필요하지 않습니다. 결과 JSON은 운영체제 임시 디렉터리에 생성됩니다.

픽셀 검증은 원 밖의 한국어 유지·원 중심의 영어·가장자리만 굴절/RGB 분리, 포인터의 전역 곡률 변화·자동 흐름·팔레트·명도·그레인·GPU 자원 해제를 확인합니다. 초기 테마와 토글, 작은 화면의 언어 전환과 입력, WebGL 대체 화면은 실제 앱의 Chromium 검증으로 확인합니다. 실제 iOS·Android 기기의 성능을 측정한 것은 아닙니다.

이번 변경은 기존 테스트 107개, 실제 WebGL 검증 51개와 프로덕션 빌드를 통과했습니다. 홈·제품 탐색·내 제품의 세 정적 시점을 비교한 실제 글자 대비는 작은 글자 5.29:1 이상, 큰 제목 3.20:1 이상이었고 영어 렌즈 중앙은 4.02:1이었습니다. 특정 화면·시점의 측정이며 모든 프레임의 최소 대비를 보장하는 수치는 아닙니다. 전역 변형 검증의 단순 이동 비교는 겹침 40% 이상인 정수 이동을 검사하고, 각 겹침 영역의 RGB 오차는 8px 간격으로 샘플링합니다.

이전의 ‘포인터 반경 밖 픽셀 불변’과 `6336c56` 대비 3초 변화량은 국소 밀어내기 버전의 검증입니다. 영상 기준으로 전체 장면을 휘는 현재 효과에는 그 조건을 적용하지 않습니다.
