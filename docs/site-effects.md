# 공통 유체 그라데이션과 텍스트 렌즈

기존 홈·제품 탐색·내 고민·내 제품·더보기·상세·구매에 같은 배경을 적용합니다. 별도 랜딩 페이지는 없으며 `?view=landing`도 실제 홈으로 연결합니다.

## 현재 화면과 동작

- 기본 라이트 화면과 수동 다크 모드를 제공합니다. 헤더에서 전환하며 선택은 기기에 저장합니다. 저장소를 사용할 수 없어도 현재 화면에서 전환됩니다.
- 흰색 `#f7fbff`·아이스 블루 `#dcefff`·하늘색 `#acdfff`·블루 `#4c8ee8`의 유체 그라데이션을 사용합니다. 라이트에서는 흰색이 가장 넓은 색 영역을 차지하며, 화면 전체를 흰색 막이나 감마로 밝히지 않습니다. 실제 비율은 움직임에 따라 달라집니다. 화면을 크게 차지하는 연속적인 색 영역이 마우스와 시간에 따라 늘어나고 서로 밀어내며, 누적 경로와 자동 흐름을 반영합니다.
- 다크 모드는 영상에 나타난 검정·남색·청록·따뜻한 오렌지의 유동 팔레트를 사용합니다. 읽기 표면과 전경색도 다크 모드에 맞춥니다.
- 스크롤 위치나 페이지 종류에 따라 다른 팔레트·장면으로 바꾸지 않습니다. 고정 Canvas와 시간·이동 이력을 재사용하며, 스크롤 입력은 이어지는 흐름을 변형합니다. 홈이 화면 밖으로 나가거나 검색 결과가 나타나도 장면을 갑자기 교체하지 않습니다. 영역별 IntersectionObserver 전환은 제거했습니다.
- 렌즈 중심의 넓은 중력장과 회전 성분으로 인접한 색 흐름이 둥글게 휘어집니다. 멀어질수록 영향이 약해지고, 화면 전체가 한 방향으로 밀리는 움직임은 줄였습니다.
- 마우스의 이동 경로를 누적한 변형은 원래 위치로 돌아와도 즉시 사라지지 않고 천천히 완화됩니다. 한 손가락 터치 이동과 네이티브 스크롤도 passive 이벤트로 같은 이력에 반영합니다. 이동 경로의 정규화 수치만 휘발성 메모리에 유지하며 저장소나 서버에 보관하지 않습니다. coarse 포인터 기기에서는 자동 흐름을 기본의 2배로 진행하며, 입자 크기·강도는 유지합니다.
- 그레인은 최종 출력 기준 1.3px 셀로 이전 1px보다 조금 키웠고 강도는 .045로 유지했습니다. 무거운 배경은 최대 180만 픽셀 내부 FBO에서 계산하고 최종 합성은 최대 DPR 3·840만 픽셀에서 수행하므로, 내부 예산을 낮춰도 입자가 커지지 않습니다.
- 데스크톱의 원형 렌즈 커서는 메뉴·버튼·빈 공간을 포함한 전역에서 유지합니다. 페이지 이동에도 포인터 위치를 이어갑니다. 글자 굴절은 16px 이상 비조작 정적 문구에만 적용하고, 메뉴·버튼·링크·입력·레이블·작은 글자와 이를 섞은 문장은 네이티브 상태로 둡니다. 대표 제목만 원 안에서 한국어가 영어로 바뀝니다.
- 원 밖의 글자는 HTML을 그대로 표시합니다. 활성 문구 전체를 숨겨 Canvas 글자로 교체하지 않으며, 같은 위치의 원형 마스크와 투명한 Canvas로 원 안쪽만 그립니다. 확대·굴절·색 분리는 원 안에서만 적용됩니다. 볼록 확대는 중심부 약 11%, 빨강·노랑과 파랑·청록의 색 분리는 중심 0에서 외곽 최대 3.4px이며, 분리된 색 날개에는 100% 불투명도를 적용합니다. 글자 본체의 불투명도는 유지합니다.
- 터치·coarse·hover 불가·750px 이하에서는 한국어 원문만 표시합니다. 한영 버튼은 생성하지 않습니다. WebGL 대체 화면도 한국어를 유지합니다.

상단 헤더와 내비게이션은 흰색 채움을 12–22%로 낮추고 24px 블러를 적용해 뒤쪽 색을 드러냅니다. 홈 전체를 덮던 흰색 보호막은 제거했으며, 읽기 패널은 별도의 유리 표면을 사용합니다. 기존 5개 메뉴, 사진·제형 전환, 리뷰·연구·질문·구매 입력은 유지합니다.

`backdrop-ink.js`는 배경 위의 등록 문구와 대응 영어를 라이트에서는 검정 `#171717`, 다크에서는 밝은 `#f7fbff`로 표시합니다. 배경의 순간 밝기에 따라 글자색을 바꾸지는 않습니다. 읽기 패널과 컨트롤은 기존의 어두운 글자색을 유지하고, 강제 색상 모드는 시스템 색상을 사용합니다.

`site-wide-text-lens.js`는 적격 문구만 로컬 텍스처로 그립니다. 텍스트·이미지 전체를 HTML 캡처하거나 서버에 보내지 않습니다. 원 밖은 네이티브 글자를 유지하므로 Canvas와 브라우저 글꼴 렌더링의 차이로 전체 문구가 바뀌어 보이지 않습니다. 조작 요소가 섞인 문장은 통째로 원래 상태를 유지합니다. 텍스트 렌더러는 페이지당 하나이며, 입력·선택·클릭·스크롤은 가로채지 않습니다. 히어로는 부모 폭을 사용해 `100vw`와 스크롤바 너비의 차이에 의한 가로 넘침을 줄입니다.

화면 오른쪽에는 비커 눈금 형태의 스크롤 위치 표시가 있습니다. 데스크톱 폭 26px·높이 64vh, 긴 눈금 12px·두께 2px와 7px 삼각형으로 키웠습니다. 31개 눈금과 삼각형 표식으로 현재 문서의 0–100% 위치를 표시하며, 스크롤할 내용이 없으면 숨깁니다. 750px 이하에서는 폭 12px·높이 48vh, 긴 눈금 6px와 4px 삼각형으로 표시합니다. 클릭·드래그·포커스를 받지 않고 passive 스크롤 이벤트를 따라갑니다. 문서 길이·글꼴·이미지 크기가 달라지면 다시 계산하며, 스크롤 위치를 강제로 바꾸지 않습니다.

Canvas는 링크·네이티브 스크롤·포커스를 가로채지 않으며 터치·스크롤 처리에서 `preventDefault()`를 호출하지 않습니다. 화면 전환 직후의 자동 스크롤은 제외하며 사용자의 휠·터치·키보드 스크롤과 큰 위치 이동은 제한된 강도로 반영합니다. 동작 줄이기·투명도 감소·고대비·강제 색상에서는 배경 이력을 초기화하고 정적 상태를 유지하며, 비활성 탭에서는 이력과 그리기를 일시 정지합니다. 렌즈의 동작 줄이기는 지연 추종을 즉시 반영합니다. WebGL 실패 시 CSS 대체 배경과 한국어 HTML을 표시합니다.

## 설정과 파일

`site-effects-config.js`에서 팔레트·시간·회전·변형·그레인 강도/셀 크기·배경/출력 픽셀 예산·포인터 범위와 강도·보간·이력 완화·터치/스크롤 반응·coarse 자동 흐름 배수·제목 문구를 조절합니다. `hero.ko`, `hero.en`, `hero.offsets`는 홈의 세 줄 제목과 시작점을 정합니다. 렌즈의 `minFontSize` 기본값은 16px입니다.

렌즈의 정규화 반경을 `ρ`라고 할 때 채널별 이동량은 `rgbOffset × ρ³ × min(abs(refraction) / 7, 1)`입니다. 기본 최대 이동량은 3.4px이고, `fringeOpacity` 기본값은 1입니다. 선명한 본체를 유지하면서 그 바깥의 색을 불투명하게 표시합니다. 중심 확대의 샘플 좌표 수축은 `.10 × (1 − ρ²)²`에 같은 굴절 강도를 곱하며, 경계로 갈수록 0이 됩니다. 색 분리는 얇은 외곽선에만 한정하지 않고 원 안에서 반경에 따라 증가합니다.

| 파일 | 역할 |
| --- | --- |
| `site-effects-config.js` | 공통 팔레트·중력장·입자·렌즈·문구 설정 |
| `site-background.js` | 테마별 유동 팔레트·누적 이력을 반영한 전역 좌표 변형·내부 FBO·입자 합성 |
| `background-motion.js` | 정규화 이동의 누적·회전·위상과 느린 완화를 계산하는 순수 함수 |
| `ambient-background.js` | 전역 배경 수명·마우스/터치/스크롤 입력·coarse 2배 흐름·접근성·이력 보존 |
| `backdrop-ink.js` | 배경 위 전경 문구의 검정 고정·읽기 패널 제외·한영 대응 줄 표시 |
| `site-text-effects.js` | 기존 대표 제목의 한국어·영어 레이어와 페이지 렌즈 수명 |
| `site-wide-text-lens.js` | 16px 이상 비조작 정적 문구 선택·네이티브 외부 마스크·전역 커서·페이지당 하나의 렌더러 |
| `landing-text-lens.js`, `landing-lens-renderer.js` | 텍스트 래스터화·원형 마스크·볼록 확대·반경에 따른 색 분리·외곽 굴절 |
| `scroll-position.js`, `scroll-position.css` | 오른쪽 31개 눈금·삼각형 스크롤 위치 표시·문서 길이 갱신 |
| `site-effects.css` | 밝은 공통 유리·타이포그래피·반응형·대체 배경 |

`landing`이라는 파일명은 재사용 렌즈 엔진을 가리키며 별도 페이지가 아닙니다. 레퍼런스의 사진·영상·폰트·소스 코드는 복제하지 않았습니다.

## 실행과 검증

기존 Vite·JavaScript·WebGL 스택을 유지합니다.

```sh
npm ci
npm run dev
# http://localhost:5173/
npm run build
node --test --test-concurrency=1
```

실제 GPU 픽셀 검증은 선택적인 Playwright 설치 후 실행합니다. 앱 실행에는 필요하지 않습니다.

```sh
npm install --no-save playwright
npx playwright install chromium
npm run verify:effects
```

시스템 브라우저는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/경로/chromium`으로 지정합니다. GPU 검증은 로컬 소스를 메모리에서 제공하며 개발 서버가 필요하지 않습니다. 결과 JSON은 운영체제 임시 디렉터리에 저장합니다. 한국어/영어 렌즈, 전체 영역의 중력 반응·연속 흐름·이전 장면 인수 무시, 밝은 팔레트와 별도 다크 팔레트·색 영역의 변화와 범위, 입자 크기·예산/DPR 독립성·GPU 자원 해제를 확인합니다. 실제 iOS·Android 하드웨어 성능을 보장하는 측정은 아닙니다.

이번 변경에서 Node 테스트 113개·프로덕션 빌드·광학/배경/입자 GPU 검증 78개(28·22·28)가 통과했습니다. 검정 배경이 없고 밝기 범위가 유지됨, 경로에 따른 실제 픽셀 변화, 입자 크기, 중심에서 외곽으로 증가하는 색 분리, 불투명 색 날개와 본체 보존, 렌즈 밖 투명 출력을 확인합니다.

Chromium 화면 검증에서는 메뉴·버튼·작은 글자 위에서 문구 효과만 빠지고 커서는 유지되며, 페이지 이동에도 커서 위치를 이어감을 확인했습니다. 1440·2035·2560px와 DPR 1·2에서 글자 좌표가 유지됐고, 광학 변형을 끈 독립 비교의 원 밖 픽셀 차이는 0이었습니다. 320px의 8개 화면에서 한국어·입력·가로 넘침 없음, 커진 스크롤 눈금의 0·50·100% 위치와 짧은 문서 숨김, WebGL 대체 화면도 확인했습니다. 실제 iOS·Android 하드웨어 성능 측정은 아닙니다.

상단 페이지 제목은 홈과 같은 굵기 600을 사용합니다. 모바일 내 고민 메뉴의 말풍선 아이콘은 물음표와 외곽선 사이에 간격을 둡니다.
