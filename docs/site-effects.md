# 공통 유체 그라데이션과 제목 렌즈

기존 홈·제품 탐색·내 고민·내 제품·더보기·상세·구매에 같은 밝은 배경을 적용합니다. 별도 랜딩 페이지는 없으며 `?view=landing`도 실제 홈으로 연결합니다.

## 현재 화면과 동작

- 라이트 화면만 제공합니다. 다크 전환 버튼·초기 다크 설정·저장한 테마 읽기는 제거했으며 시스템이나 과거 저장값이 다크여도 밝은 화면을 표시합니다.
- 흰색·파랑·부드러운 회색이 넓게 겹치는 하나의 유체 그라데이션을 사용합니다. 포인터 주변의 반발·회전 성분이 화면 전체 좌표를 휘고, 넓은 두 색 흐름을 섞습니다. 포인터의 빠른 추종과 느린 관성, 자동 흐름은 유지합니다.
- 스크롤 위치나 페이지 종류에 따라 배경을 전환하지 않습니다. 고정 Canvas와 시간·포인터 상태를 재사용하므로 홈이 화면 밖으로 나가거나 검색 결과가 나타나도 색상과 노출이 바뀌지 않습니다. 영역별 IntersectionObserver 전환은 제거했습니다.
- 그레인은 최종 출력 기준 1.3px 셀로 이전 1px보다 조금 키웠고 강도는 .045로 유지했습니다. 무거운 배경은 최대 180만 픽셀 내부 FBO에서 계산하고 최종 합성은 최대 DPR 3·840만 픽셀에서 수행하므로, 내부 예산을 낮춰도 입자가 커지지 않습니다.
- 데스크톱의 넓은 마우스 환경에서는 제목의 한국어가 원형 렌즈 안에서 영어로 바뀝니다. 중심 글자는 또렷하고 가장자리의 얇은 띠에만 굴절과 RGB 분리를 적용합니다.
- 터치·coarse·hover 불가·750px 이하에서는 한국어 원문만 표시합니다. 한영 버튼은 생성하지 않습니다. WebGL 대체 화면도 한국어를 유지합니다.

흰 유리 표면과 짙은 글자를 공통으로 사용하며 홈 제목·내비게이션·검색의 재질을 통일합니다. 홈의 보호막은 끝에서 부드럽게 사라지고 브랜드 영역도 같은 밝은 유리로 구성해 스크롤 경계를 완화합니다. 기존 5개 메뉴, 사진·제형 전환, 리뷰·연구·질문·구매 입력은 유지합니다.

입력 문장·리뷰·제품 사진을 캡처하지 않습니다. 내부 텍스처는 수학적으로 그린 배경색만 담고, 텍스트 렌즈는 등록된 대표 제목만 그립니다. Canvas는 링크·네이티브 스크롤·포커스를 가로채지 않습니다. 동작 줄이기에서는 정지하고 비활성 탭에서는 그리기를 중단합니다. WebGL 실패 시 정적 CSS 배경과 한국어 HTML을 표시하며 고대비·투명도 감소·강제 색상도 지원합니다.

## 설정과 파일

`site-effects-config.js`에서 팔레트·시간·회전·변형·밝기 하한·그레인 강도/셀 크기·배경/출력 픽셀 예산·포인터 범위와 강도·보간·제목 문구를 조절합니다. `hero.ko`, `hero.en`, `hero.offsets`는 홈의 세 줄 제목과 시작점을 정합니다.

| 파일 | 역할 |
| --- | --- |
| `site-effects-config.js` | 공통 팔레트·중력장·입자·렌즈·문구 설정 |
| `site-background.js` | 하나의 밝은 장면·전역 좌표 변형·내부 FBO·입자 합성 |
| `ambient-background.js` | 전역 배경 수명·포인터 관성·접근성·스크롤 상태 보존 |
| `site-text-effects.js` | 기존 대표 제목의 한국어·영어 레이어 |
| `landing-text-lens.js`, `landing-lens-renderer.js` | 데스크톱 텍스트 마스크·가장자리 굴절 |
| `site-effects.css` | 밝은 공통 유리·타이포그래피·반응형·대체 배경 |

`landing`이라는 파일명은 재사용 렌즈 엔진을 가리키며 별도 페이지가 아닙니다. 레퍼런스의 사진·영상·폰트·소스 코드는 복제하지 않았습니다.

## 실행과 검증

기존 Vite·JavaScript·WebGL 스택을 유지합니다.

```sh
npm ci
npm run dev
# http://localhost:5173/
npm run build
node --test --test-concurrency=1
```

실제 GPU 픽셀 검증은 선택적인 Playwright 설치 후 실행합니다. 앱 실행에는 필요하지 않습니다.

```sh
npm install --no-save playwright
npx playwright install chromium
npm run verify:effects
```

시스템 브라우저는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/경로/chromium`으로 지정합니다. GPU 검증은 로컬 소스를 메모리에서 제공하며 개발 서버가 필요하지 않습니다. 결과 JSON은 운영체제 임시 디렉터리에 저장합니다. 한국어/영어 렌즈, 전체 영역의 중력 반응·연속 흐름·이전 장면 인수 무시, 밝은 글자 대비, 입자 크기·예산/DPR 독립성·GPU 자원 해제를 확인합니다. 실제 iOS·Android 하드웨어 성능을 보장하는 측정은 아닙니다.

현재 변경은 기존 테스트 107개와 GPU 검증 64개를 통과했습니다. Chromium에서 같은 시간을 고정한 채 홈·경계·중간·하단 다섯 스크롤 위치의 배경 픽셀이 동일하고 Canvas가 재생성되지 않는 것을 확인했습니다. 320px 모바일 8개 화면에서 한국어만 노출, 전환 버튼 없음, 검색 조합 입력·구매 입력·WebGL 대체 화면을 확인했습니다.
