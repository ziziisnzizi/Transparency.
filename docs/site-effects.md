# 공통 유체 그라데이션과 텍스트 렌즈

기존 홈·제품 탐색·내 고민·내 제품·더보기·상세·구매에 같은 배경을 적용합니다. 별도 랜딩 페이지는 없으며 `?view=landing`도 실제 홈으로 연결합니다.

## 현재 화면과 동작

- 라이트 화면만 제공합니다. 다크 전환 버튼·초기 다크 설정·저장한 테마 읽기는 제거했으며 시스템이나 과거 저장값이 다크여도 밝은 화면을 표시합니다.
- 실제 검정 영역과 밝은 흰색·선명한 파란 띠가 넓게 겹치는 하나의 유체 그라데이션을 사용합니다. UI는 라이트이며 배경의 검정은 그래픽 구성 색입니다. 전체 밝기 하한·감마로 검정을 끌어올리는 처리·전체 흰색 덧씌우기를 제거했습니다. 포인터 주변의 반발·회전 성분이 화면 전체 좌표를 휘고, 넓은 두 색 흐름을 섞습니다. 포인터의 빠른 추종과 느린 관성, 자동 흐름은 유지합니다.
- 스크롤 위치나 페이지 종류에 따라 다른 팔레트·장면으로 바꾸지 않습니다. 고정 Canvas와 시간·이동 이력을 재사용하며, 스크롤 입력은 이어지는 흐름을 변형합니다. 홈이 화면 밖으로 나가거나 검색 결과가 나타나도 장면을 갑자기 교체하지 않습니다. 영역별 IntersectionObserver 전환은 제거했습니다.
- 마우스의 이동 경로를 누적한 변형은 원래 위치로 돌아와도 즉시 사라지지 않고 천천히 완화됩니다. 한 손가락 터치 이동과 네이티브 스크롤도 passive 이벤트로 같은 이력에 반영합니다. 이동 경로의 정규화 수치만 휘발성 메모리에 유지하며 저장소나 서버에 보관하지 않습니다. coarse 포인터 기기에서는 자동 흐름을 기본의 2배로 진행하며, 입자 크기·강도는 유지합니다.
- 그레인은 최종 출력 기준 1.3px 셀로 이전 1px보다 조금 키웠고 강도는 .045로 유지했습니다. 무거운 배경은 최대 180만 픽셀 내부 FBO에서 계산하고 최종 합성은 최대 DPR 3·840만 픽셀에서 수행하므로, 내부 예산을 낮춰도 입자가 커지지 않습니다.
- 데스크톱의 넓은 마우스 환경에서는 16px 이상인 비조작 정적 문구에 렌즈를 적용합니다. 대표 제목의 한국어는 원 안에서 영어로 바뀌고 일반 정적 문구는 번역하지 않습니다. 메뉴·버튼·링크·입력·레이블·펼침 컨트롤과 16px 미만의 작은 글자는 제외합니다. 조작 요소 뒤에 큰 제목이 있어도 뒤쪽 텍스트를 대신 굴절하지 않습니다. 기본 설정의 완만한 볼록 렌즈는 중심부를 약 11% 선명하게 확대합니다. RGB 분리는 중심에서 거의 0이며, 원 바깥쪽으로 갈수록 연속적으로 증가해 경계에서 최대 2px가 됩니다. 바깥의 얇은 굴절 띠는 유지하고 원 밖은 네이티브 글자 그대로입니다. 굴절을 0으로 설정하면 확대와 RGB 분리도 사라집니다.
- 터치·coarse·hover 불가·750px 이하에서는 한국어 원문만 표시합니다. 한영 버튼은 생성하지 않습니다. WebGL 대체 화면도 한국어를 유지합니다.

상단 헤더와 내비게이션은 흰색 채움을 12–22%로 낮추고 24px 블러를 적용해 뒤쪽 색을 드러냅니다. 홈 전체를 덮던 흰색 보호막은 제거했으며, 읽기 패널은 별도의 유리 표면을 사용합니다. 기존 5개 메뉴, 사진·제형 전환, 리뷰·연구·질문·구매 입력은 유지합니다.

`backdrop-ink.js`는 배경 위에 직접 놓인 등록 문구를 흰색으로 고정합니다. 배경 밝기를 표본으로 읽거나 검정·흰색 사이를 전환하지 않으며, CSS 대체 배경에서도 같은 규칙을 사용합니다. 대표 제목의 한국어·영어 대응 줄에도 같은 흰색을 적용합니다. 흰색 읽기 카드와 밝은 선택 컨트롤은 기존의 어두운 글자색을 유지합니다. CSS 변수로 전경만 표시하며 배경·글자 크기·굵기·배치를 바꾸거나 전체 흰색 막을 추가하지 않습니다. 강제 색상 모드에서는 시스템 색상을 사용합니다.

`site-wide-text-lens.js`는 현재 가리킨 적격 정적 텍스트의 문구·글꼴·화면 위치를 Canvas 텍스처로 다시 그립니다. 조작 요소·작은 글자·입력 필드·편집 영역·제품 사진·SVG·코드·열린 대화상자는 제외합니다. 전체 페이지를 이미지로 캡처하거나 렌즈용 문구를 서버로 보내지 않습니다. 배경용 WebGL과 별도로 텍스트 렌즈는 페이지당 하나의 WebGL 렌더러를 재사용하며, 문장마다 새 컨텍스트를 만들지 않습니다.

화면 오른쪽에는 비커 눈금 형태의 스크롤 위치 표시가 있습니다. 31개 눈금과 삼각형 표식으로 현재 문서의 0–100% 위치를 표시하며, 스크롤할 내용이 없으면 숨깁니다. 750px 이하에서는 폭·높이·눈금·삼각형을 줄인 형태로 표시합니다. 클릭·드래그·포커스를 받지 않고 passive 스크롤 이벤트를 따라갑니다. 문서 길이·글꼴·이미지 크기가 달라지면 다시 계산하며, 스크롤 위치를 강제로 바꾸지 않습니다.

Canvas는 링크·네이티브 스크롤·포커스를 가로채지 않으며 터치·스크롤 처리에서 `preventDefault()`를 호출하지 않습니다. 화면 전환 직후의 스크롤과 큰 위치 점프는 새 제스처로 누적하지 않습니다. 동작 줄이기·투명도 감소·고대비·강제 색상에서는 배경 이력을 초기화하고 정적 상태를 유지하며, 비활성 탭에서는 이력과 그리기를 일시 정지합니다. 렌즈의 동작 줄이기는 지연 추종을 즉시 반영합니다. WebGL 실패 시 CSS 대체 배경과 한국어 HTML을 표시합니다.

## 설정과 파일

`site-effects-config.js`에서 팔레트·시간·회전·변형·그레인 강도/셀 크기·배경/출력 픽셀 예산·포인터 범위와 강도·보간·이력 완화·터치/스크롤 반응·coarse 자동 흐름 배수·제목 문구를 조절합니다. `hero.ko`, `hero.en`, `hero.offsets`는 홈의 세 줄 제목과 시작점을 정합니다. 렌즈의 `minFontSize` 기본값은 16px입니다.

렌즈의 정규화 반경을 `ρ`라고 할 때 채널별 이동량은 `rgbOffset × ρ³ × min(abs(refraction) / 7, 1)`입니다. 기본 최대 이동량은 2px입니다. 중심 확대의 샘플 좌표 수축은 `.10 × (1 − ρ²)²`에 같은 굴절 강도를 곱하며, 경계로 갈수록 0이 됩니다. 색 분리는 얇은 외곽선에만 한정하지 않고 원 안에서 반경에 따라 증가합니다.

| 파일 | 역할 |
| --- | --- |
| `site-effects-config.js` | 공통 팔레트·중력장·입자·렌즈·문구 설정 |
| `site-background.js` | 검정·흰색·코발트 단일 장면·누적 이력을 반영한 전역 좌표 변형·내부 FBO·입자 합성 |
| `background-motion.js` | 정규화 이동의 누적·회전·위상과 느린 완화를 계산하는 순수 함수 |
| `ambient-background.js` | 전역 배경 수명·마우스/터치/스크롤 입력·coarse 2배 흐름·접근성·이력 보존 |
| `backdrop-ink.js` | 배경 위 전경 문구의 흰색 고정·읽기 패널 제외·한영 대응 줄 표시 |
| `site-text-effects.js` | 기존 대표 제목의 한국어·영어 레이어와 페이지 렌즈 수명 |
| `site-wide-text-lens.js` | 16px 이상 비조작 정적 문구 선택·원문 재사용·페이지당 하나의 데스크톱 렌즈 |
| `landing-text-lens.js`, `landing-lens-renderer.js` | 텍스트 래스터화·원형 마스크·볼록 확대·반경에 따른 색 분리·외곽 굴절 |
| `scroll-position.js`, `scroll-position.css` | 오른쪽 31개 눈금·삼각형 스크롤 위치 표시·문서 길이 갱신 |
| `site-effects.css` | 밝은 공통 유리·타이포그래피·반응형·대체 배경 |

`landing`이라는 파일명은 재사용 렌즈 엔진을 가리키며 별도 페이지가 아닙니다. 레퍼런스의 사진·영상·폰트·소스 코드는 복제하지 않았습니다.

## 실행과 검증

기존 Vite·JavaScript·WebGL 스택을 유지합니다.

```sh
npm ci
npm run dev
# http://localhost:5173/
npm run build
node --test --test-concurrency=1
```

실제 GPU 픽셀 검증은 선택적인 Playwright 설치 후 실행합니다. 앱 실행에는 필요하지 않습니다.

```sh
npm install --no-save playwright
npx playwright install chromium
npm run verify:effects
```

시스템 브라우저는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/경로/chromium`으로 지정합니다. GPU 검증은 로컬 소스를 메모리에서 제공하며 개발 서버가 필요하지 않습니다. 결과 JSON은 운영체제 임시 디렉터리에 저장합니다. 한국어/영어 렌즈, 전체 영역의 중력 반응·연속 흐름·이전 장면 인수 무시, 실제 검정/흰색/파랑의 면적과 범위, 입자 크기·예산/DPR 독립성·GPU 자원 해제를 확인합니다. 실제 iOS·Android 하드웨어 성능을 보장하는 측정은 아닙니다.

이번 변경에서 Node 테스트 113개·프로덕션 빌드·GPU 검증 72개(광학 렌즈 24개·배경 20개·입자 28개)가 통과했습니다. 새 순수 모델 검사 6개는 입력 불변성·재현성·닫힌 경로와 방향·장시간 상태 범위·정지 후 완화·시간 간격 독립성을 확인합니다. 배경 GPU 검증은 시간·최종 포인터·짧은 잔상·속도를 같게 둔 상태에서 이동 경로만 바꿔 실제 픽셀 차이를 확인합니다. 해당 표본의 평균 RGB 차이는 약 41/255이며, 같은 경로 재생의 픽셀 차이는 0입니다.

별도 Chromium 화면 검증에서는 1440px에서 큰 정적 제목만 렌즈를 사용하고, 버튼·내비게이션·작은 본문·링크와 혼합 문장의 작은 주석은 숨기거나 캡처하지 않음을 확인했습니다. 눈금의 위·중간·아래 위치가 0·50·100%에 맞고, 스크롤이 사라지면 숨김을 확인했습니다. 320px의 8개 화면에서 한국어·입력·가로 넘침·눈금 유지와 한글 조합 검색도 확인했습니다. 동작 감소 환경의 고정 배경과 WebGL 대체 화면은 유지합니다.

실제 동작 검증에서는 한 프레임 안의 빠른 닫힌 마우스 경로도 이력을 남기고, 휠 스크롤·터치 입력·모바일 스와이프가 같은 상태에 반영됨을 확인했습니다. 페이지 이동 뒤에도 Canvas와 이력은 유지되며, 동작 감소로 전환하면 이력과 자동 흐름을 멈춥니다. 모바일의 자동 흐름과 390px의 네이티브 스크롤·축소 눈금·가로 넘침 없음도 확인했습니다. 소프트웨어 Chromium에서 수행한 검증이며 실제 iOS·Android 하드웨어 성능 측정은 아닙니다.

이전 6c3a7e3의 고정 프레임은 최소 밝기가 약 .473으로 검정 영역이 없었습니다. 수정한 배경의 이전 표본은 밝기 .00068~.972, 포인터 왼쪽에서 검정 면적 0%·오른쪽에서 약 64%로 달라졌습니다. 특정 시간·위치의 기록이며 모든 프레임에 같은 비율을 보장하는 값은 아닙니다.
