# 공통 유체 그라데이션과 텍스트 렌즈

기존 홈·제품 탐색·내 고민·내 제품·더보기·상세·구매에 같은 배경을 적용합니다. 별도 랜딩 페이지는 없으며 `?view=landing`도 실제 홈으로 연결합니다.

## 현재 화면과 동작

- 라이트 화면만 제공합니다. 다크 전환 버튼·초기 다크 설정·저장한 테마 읽기는 제거했으며 시스템이나 과거 저장값이 다크여도 밝은 화면을 표시합니다.
- 실제 검정 영역과 밝은 흰색·선명한 파란 띠가 넓게 겹치는 하나의 유체 그라데이션을 사용합니다. UI는 라이트이며 배경의 검정은 그래픽 구성 색입니다. 전체 밝기 하한·감마로 검정을 끌어올리는 처리·전체 흰색 덧씌우기를 제거했습니다. 포인터 주변의 반발·회전 성분이 화면 전체 좌표를 휘고, 넓은 두 색 흐름을 섞습니다. 포인터의 빠른 추종과 느린 관성, 자동 흐름은 유지합니다.
- 스크롤 위치나 페이지 종류에 따라 배경을 전환하지 않습니다. 고정 Canvas와 시간·포인터 상태를 재사용하므로 홈이 화면 밖으로 나가거나 검색 결과가 나타나도 색상과 노출이 바뀌지 않습니다. 영역별 IntersectionObserver 전환은 제거했습니다.
- 그레인은 최종 출력 기준 1.3px 셀로 이전 1px보다 조금 키웠고 강도는 .045로 유지했습니다. 무거운 배경은 최대 180만 픽셀 내부 FBO에서 계산하고 최종 합성은 최대 DPR 3·840만 픽셀에서 수행하므로, 내부 예산을 낮춰도 입자가 커지지 않습니다.
- 데스크톱의 넓은 마우스 환경에서는 대표 제목의 한국어가 원형 렌즈 안에서 영어로 바뀝니다. 일반 본문·링크·버튼 등 정적 문구에도 같은 렌즈를 적용하되, 해당 문구는 원문을 그대로 재사용하며 번역하지 않습니다. 중심 글자는 또렷하고 가장자리의 얇은 띠에만 굴절과 RGB 분리를 적용합니다.
- 터치·coarse·hover 불가·750px 이하에서는 한국어 원문만 표시합니다. 한영 버튼은 생성하지 않습니다. WebGL 대체 화면도 한국어를 유지합니다.

상단 헤더와 내비게이션은 흰색 채움을 12–22%로 낮추고 24px 블러를 적용해 뒤쪽 색을 드러냅니다. 홈 전체를 덮던 흰색 보호막은 제거했으며, 읽기 패널은 별도의 유리 표면을 사용합니다. 기존 5개 메뉴, 사진·제형 전환, 리뷰·연구·질문·구매 입력은 유지합니다.

`backdrop-ink.js`는 등록된 전경 문구 위치에서 실제 배경 FBO의 색을 표본으로 읽고 검정 또는 흰색 글자 중 대비가 나은 쪽을 선택합니다. 실제 글자 범위에서 표본을 읽으며, 헤더와 읽기 패널의 흰색 재질도 계산에 반영합니다. WebGL이 없을 때는 CSS 대체 그라데이션의 작은 정적 색상 지도에서 표본을 읽습니다. CSS 변수로 글자색만 바꾸며 배경·글자 크기·굵기·배치를 바꾸거나 전체 흰색 막을 추가하지 않습니다. 유리 읽기 패널의 기본 글자색은 차콜입니다. 표본 기반 선택이므로 모든 픽셀·프레임에서 일정 대비를 보장하는 방식은 아닙니다.

`site-wide-text-lens.js`는 현재 가리킨 정적 텍스트의 문구·글꼴·화면 위치를 Canvas 텍스처로 다시 그립니다. 표시된 리뷰 문장도 정적 텍스트에 포함될 수 있지만 입력 필드·편집 영역·제품 사진·SVG·코드·열린 대화상자는 제외합니다. 전체 페이지를 이미지로 캡처하거나 렌즈용 문구를 서버로 보내지 않습니다. 배경용 WebGL과 별도로 텍스트 렌즈는 페이지당 하나의 WebGL 렌더러를 재사용하며, 문장마다 새 컨텍스트를 만들지 않습니다.

Canvas는 링크·네이티브 스크롤·포커스를 가로채지 않습니다. 동작 줄이기에서는 배경 자동 흐름을 멈추고 렌즈의 지연 추종을 즉시 반영하며, 비활성 탭에서는 그리기를 중단합니다. WebGL 실패 시 정적 CSS 배경과 한국어 HTML을 표시하며 고대비·투명도 감소·강제 색상도 지원합니다.

## 설정과 파일

`site-effects-config.js`에서 팔레트·시간·회전·변형·그레인 강도/셀 크기·배경/출력 픽셀 예산·포인터 범위와 강도·보간·제목 문구를 조절합니다. `hero.ko`, `hero.en`, `hero.offsets`는 홈의 세 줄 제목과 시작점을 정합니다.

| 파일 | 역할 |
| --- | --- |
| `site-effects-config.js` | 공통 팔레트·중력장·입자·렌즈·문구 설정 |
| `site-background.js` | 검정·흰색·코발트 단일 장면·전역 좌표 변형·내부 FBO·입자 합성·색 표본 읽기 |
| `ambient-background.js` | 전역 배경 수명·포인터 관성·접근성·스크롤 상태 보존 |
| `backdrop-ink.js` | 배경 표본에 따른 전경 글자색 선택·CSS 변수 갱신 |
| `site-text-effects.js` | 기존 대표 제목의 한국어·영어 레이어와 페이지 렌즈 수명 |
| `site-wide-text-lens.js` | 정적 문구 선택·원문 텍스처 재사용·페이지당 하나의 데스크톱 렌즈 |
| `landing-text-lens.js`, `landing-lens-renderer.js` | 텍스트 래스터화 유틸리티·마스크·가장자리 굴절 엔진 |
| `site-effects.css` | 밝은 공통 유리·타이포그래피·반응형·대체 배경 |

`landing`이라는 파일명은 재사용 렌즈 엔진을 가리키며 별도 페이지가 아닙니다. 레퍼런스의 사진·영상·폰트·소스 코드는 복제하지 않았습니다.

## 실행과 검증

기존 Vite·JavaScript·WebGL 스택을 유지합니다.

```sh
npm ci
npm run dev
# http://localhost:5173/
npm run build
node --test --test-concurrency=1
```

실제 GPU 픽셀 검증은 선택적인 Playwright 설치 후 실행합니다. 앱 실행에는 필요하지 않습니다.

```sh
npm install --no-save playwright
npx playwright install chromium
npm run verify:effects
```

시스템 브라우저는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/경로/chromium`으로 지정합니다. GPU 검증은 로컬 소스를 메모리에서 제공하며 개발 서버가 필요하지 않습니다. 결과 JSON은 운영체제 임시 디렉터리에 저장합니다. 한국어/영어 렌즈, 전체 영역의 중력 반응·연속 흐름·이전 장면 인수 무시, 실제 검정/흰색/파랑의 면적과 범위, 입자 크기·예산/DPR 독립성·GPU 자원 해제를 확인합니다. 실제 iOS·Android 하드웨어 성능을 보장하는 측정은 아닙니다.

이번 변경에서 Node 테스트 107개와 프로덕션 빌드가 통과했습니다. GPU 검증도 배경 상호작용 17개, 입자 28개, 한국어·영어 렌즈 20개를 다시 실행해 모두 통과했습니다. 별도 Chromium 화면 검증에서는 1440px의 제목·메뉴·본문·제품명 렌즈가 하나의 렌더러를 재사용하고, 일반 문구는 원문 텍스처를 사용함을 확인했습니다. 고정 시간의 5개 스크롤 위치에서 배경 픽셀이 동일했으며, 한글 조합·검색·클릭과 320px의 홈·제품 탐색·내 제품·더보기·내 고민·검색 결과·상세·구매 8개 화면의 한국어·입력·가로 넘침도 확인했습니다. WebGL 대체 화면과 동작 감소 설정도 확인했습니다. 소프트웨어 Chromium 검증이며 실제 모바일 기기에서의 성능 측정은 아닙니다.

이전 6c3a7e3의 고정 프레임은 최소 밝기가 약 .473으로 검정 영역이 없었습니다. 수정한 배경의 이전 표본은 밝기 .00068~.972, 포인터 왼쪽에서 검정 면적 0%·오른쪽에서 약 64%로 달라졌습니다. 특정 시간·위치의 기록이며 모든 프레임에 같은 비율을 보장하는 값은 아닙니다.
