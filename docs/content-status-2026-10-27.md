# Transparency. 콘텐츠 적용 상태

기준일: 2026.10.27

이 문서는 사용자가 제공한 브랜드·제품·서비스 임시 설정안 중 현재 웹 프로토타입에 적용한 내용과 남은 결정을 기록합니다. 모든 제품 사양은 판매 전 개발 콘셉트이며 제조 가능성·안정성·보존력·효능 검증을 마친 처방이 아닙니다.

## 적용한 정보

- 브랜드 소개, 철학, 정보 공개 원칙, 문의 이메일과 저작권 표기
- 제품명 `세럼 S.1`, 영문명 `Transparency. Serum S.1`, 수분 세럼, 30 mL
- 개발 콘셉트·판매 전 상태와 목표 제형·향
- 글리세린 5.0%, 판테놀 1.0%, 소듐하이알루로네이트 0.1%의 임시 함량과 역할
- 완제품 시험 자료가 없다는 상태 및 성분 연구의 적용 한계
- 임시 사용 순서·사용량·빈도·보관·잔량·분리배출 안내
- 제품 FAQ 일부

## 참고 성분 연구

### 나이아신아마이드

피부 장벽과 피부 톤에 관해 연구된 성분입니다. 피부 장벽을 구성하는 지질의 생성과 멜라노솜 전달 과정에 관여하는 것으로 보고되었습니다. 일부 인체 연구에서는 나이아신아마이드를 함유한 제형을 일정 기간 사용했을 때 색소침착, 잔주름, 탄력의 개선이 관찰되었습니다.

참고 연구: Tanno 외(2000), Hakozaki 외(2002), Bissett 외(2005).

현재 제공된 S.1 개발 검토 성분 목록에는 나이아신아마이드가 포함되어 있지 않습니다. 따라서 제품 함유 성분이나 S.1 효능의 근거로 표시하지 않고 참고 성분 연구로 분리했습니다.

### 히알루론산

수분을 붙잡는 특성을 가진 보습 성분입니다. 여성 76명을 대상으로 한 연구에서는 히알루론산 0.1% 크림을 60일간 사용했을 때 대조 크림보다 피부 수분과 탄력이 개선되었습니다. 일부 분자량에서는 주름 깊이 감소도 관찰되었으며, 결과는 원료의 분자량과 제형에 따라 달라질 수 있습니다.

참고 연구: Pavicic 외(2011).

이 자료는 S.1에 검토 중인 소듐하이알루로네이트 또는 S.1 완제품의 시험 결과와 동일한 자료로 취급하지 않습니다.

### 연구 적용 범위

위 내용은 해당 성분 또는 성분을 함유한 연구용 제형에 관한 자료입니다. 세럼 S.1의 완제품 시험 결과가 아니며, 실제 제품의 효과는 함량·원료 특성·배합·사용 조건에 따라 달라질 수 있습니다.

자료 확인일: 2026.10.27

## 아직 구현하지 않은 정보

- 확정 전성분과 실제 원료별 유효 성분 함량
- 완제품 시험 결과와 원문 링크
- 실제 용기 토출량·눈금·재질·분리배출 검증
- 안정성·보존력 검토를 거친 사용기한
- 로그인·동기화·휴지통·사용기한 알림 정책의 실제 기능
- Gemini 실제 생성 답변 검증은 서버 키 등록 후 필요. 질문 전송·등록 자료 답변·출처 연결은 구현했으며, 확인 가능한 원문 연구 링크 확장은 남아 있음
- 운영 사실에 맞춘 이용약관과 개인정보 처리방침

## 추가 가상 제품 콘셉트

아래 두 제품은 사용자가 요청한 제품군 확장을 위해 만든 임시 콘텐츠입니다. 별도 제품 자료나 연구 자료가 제공된 상태가 아니므로 실제 처방·효능 정보로 사용할 수 없습니다.

### 토너 T.1

- 수분 토너, 150 mL
- 글리세린 3.0%, 판테놀 0.5%, 베타글루칸 0.1%
- 투명 워터 제형, 향료 무첨가 목표
- 세안 후 피부를 촉촉하게 정돈하는 첫 단계 콘셉트

### 크림 C.1

- 보습 크림, 50 mL
- 글리세린 5.0%, 스쿠알란 3.0%, 세라마이드 NP 0.05%
- 흰색 크림 제형, 향료 무첨가 목표
- 수분 관리 루틴의 마지막 단계에서 피부를 감싸는 콘셉트

두 제품 모두 완제품 시험 및 등록된 성분 연구가 없다고 표시합니다. 함량·사용량·제형·패키지 정보는 검증 전 개발 목표값입니다.

## 확인이 필요한 결정

나이아신아마이드를 세럼 S.1의 실제 개발 검토 성분에 포함할지 결정해야 합니다. 포함한다면 목표 함량, 제품 내 역할, 함량 선택 기준과 처방 상태를 추가한 뒤 성분·함량 화면에 반영합니다.

## 공개 문구 정리 — 2026.11.02

사용자 요청에 따라 공개 화면의 개발·콘셉트·가상·임시 표현을 브랜드 서비스 문장으로 정리했습니다. 제품 상태 표시는 T.1 → S.1 → C.1의 루틴 단계로 바꾸고, 성분 설명은 일반적인 역할을 안내하도록 수정했습니다. 이 문구 변경은 제조 처방·효능·보존력 등의 검증 상태가 바뀌었다는 의미가 아닙니다.

공개된 완제품 시험 자료가 없다는 설명과 성분 연구의 적용 범위는 유지합니다. 향료 무첨가 확정 표현과 6개월 사용기간 안내는 제거합니다. 당시의 질문 입력 전용 흐름은 아래 Gemini 질문 기능으로 확장했으며, 제품 사용 기록은 브라우저에만 저장된다고 안내합니다.

## 제품 순서와 사용자 리뷰 — 2026.11.03

- 홈과 제품 탐색의 기본 순서는 STEP 01 토너 T.1 → STEP 02 세럼 S.1 → STEP 03 크림 C.1입니다. 평점이나 리뷰 수로 다른 제품군을 순위화하지 않습니다.
- T.2처럼 같은 제품군이 추가되면 같은 그룹에 배치하고 제품명 순으로 정렬합니다. 향후 제품 비교의 범위는 같은 제품군으로 한정합니다.
- ‘별점 낮은 순’은 개별 제품의 사용자 리뷰 목록에만 적용합니다. 같은 별점의 리뷰는 최신 작성순으로 표시합니다.
- 제품별 ‘사용자 리뷰’ 탭에서 1~5점과 사용 경험을 입력하고 삭제할 수 있습니다. 다른 제품의 리뷰가 섞이지 않으며 평균과 개수도 제품별로 계산합니다.
- 전체 리뷰 수에는 제품별 작성 콘텐츠 10개와 직접 입력한 리뷰를 합산하며, 작성·예시 개수를 함께 표시합니다. 입력 리뷰가 없으면 전체 10개, 작성 0개, 예시 10개로 표시하고 평균 별점은 ‘아직 평가 없음’으로 안내합니다. 작성 콘텐츠의 별점은 평균에 합산하지 않습니다.
- 리뷰는 현재 브라우저의 localStorage에만 저장됩니다. 다른 사용자나 기기와 공유되지 않으며, 공동 수집·운영자 열람을 위해서는 별도 서버 저장소 연결이 필요합니다.

## 예시 리뷰 — 2026.11.03

사용자 요청에 따라 제품별 10개씩 총 30개의 예시 리뷰를 `review-mocks.js`에 작성했습니다. 사용감·제형·용기·눈금·사용 순서를 주제로 1~5점 의견을 포함합니다. 이 데이터는 실제 사용이나 구매에 대한 증언이 아닙니다.

제품 상세의 사용자 리뷰 탭에서 직접 입력한 리뷰와 준비된 글을 하나의 목록으로 합쳐 낮은 별점순으로 표시합니다. 별도 접기 영역과 개별 출처 배지는 사용하지 않으며, 목록 앞의 한 문단에서 준비된 글이 실제 구매 후기가 아님을 안내합니다. 준비된 글은 전체 리뷰 수에는 포함하지만 저장소에 복사하거나 평균 별점에 합산하지 않습니다. 홈·탐색 카드와 상세 화면에 작성·예시 개수를 함께 표시하고, 평균은 직접 작성한 리뷰 기준임을 안내합니다.

## 구매 화면과 로고 — 2026.11.03

로고를 마침표가 포함된 `Transparency.` 텍스트로 복원했습니다. 제품별 구매 화면은 상품 선택·수량·배송 정보·주문 금액 계산·주문 내용 확인과 수정을 제공합니다. 제안가는 T.1 18,000원, S.1 24,000원, C.1 26,000원이며 배송비는 3,000원, 상품 금액 50,000원부터 무료입니다. 중가 포지션을 위한 화면 적용 제안가로, 제조·용기 원가에 따른 마진 검토는 별도로 필요합니다.

배송 정보는 메모리에만 유지하고 전송하거나 저장하지 않습니다. 실제 결제·주문 접수는 연결되지 않았으며 최종 확인 화면에 안내합니다. 자세한 구현 범위는 `docs/purchase-flow.md`를 참고하세요.

## 제품 질문과 Gemini — 2026.11.03

기존 질문하기 탭에 질문 전송·답변·추천 질문·근거 버튼·요청 취소·재시도를 추가했습니다. 공통 제품 데이터와 서버의 공개 자료를 사용하며, Gemini 연결은 서버 환경 변수 `GEMINI_API_KEY`로 활성화합니다. 키 미등록 또는 제공업체 오류 시에는 ‘제품 자료 답변’으로 구분해 안내합니다.

질문과 제품 자료는 답변 처리를 위해 서버로 전송되고, 연결된 경우 Gemini 서비스로 전달됩니다. 대화는 브라우저 저장소나 데이터베이스에 저장하지 않으며 페이지 메모리에 제품별로 유지합니다. 키는 프런트엔드에 전달하지 않습니다. 공개된 시험 결과가 없는 내용과 개인별 적합성·사용기한은 추측하지 않습니다. 설정 및 검증 범위는 `docs/gemini-questions.md`를 참고하세요.
