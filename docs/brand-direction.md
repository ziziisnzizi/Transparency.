# Transparency. 브랜드 디자인 기준

## 사용자 제공 문구

- 메인: **가릴 것이 없으니까.** / **Transparency.**
- 서비스 소개: **궁금했던 성분부터, 나에게 맞는 사용법까지.**
- 서비스 메시지: **극도의 투명함, 손안에서.**
- 브랜드 선언: **성분에 장난 없이.** / **Transparency.**

표기 시 `가릴 것이`의 띄어쓰기를 적용합니다.

## 시각 기준

- 흑과 백, 중립 회색을 사용합니다.
- 투명한 유리, 실험기구, 검은 스포이트, 흰 패키지의 조합을 기준으로 합니다.
- 얇은 선과 넓은 여백으로 정보의 계층을 구분합니다.
- 버튼은 검은 면 또는 선으로, 선택 상태는 명확한 명암 차이로 표현합니다.
- 유리 효과는 투명한 배경·빛 반사·흐림으로 표현하되 본문 읽기와 조작을 우선합니다.
- 홈·목록·상세·내 제품·더보기에 같은 스타일을 적용합니다.
- 모바일에는 하단 메뉴를 제공합니다. 키보드 포커스와 동작 줄이기 설정을 지원합니다.

## 이미지

- `public/images/transparency-campaign.png`: 사용자가 제공한 패키지 시안을 참고하여 이미지 생성 도구로 제작한 홈 캠페인 콘셉트 이미지입니다. 실제 제품 사진이 아닙니다.
- `public/images/transparency-glass.svg`: 플라스크 형태의 세럼 용기 콘셉트 일러스트입니다.
- 크림·클렌저 용기는 CSS로 표현한 예시입니다.

제품명·성분·함량·용량은 이전 프로토타입의 예시 데이터를 유지합니다. 실제 제품 사양은 별도로 확정해야 합니다.

## 이번 변경 검증

- `node --check main.js`와 `npm run build` 통과
- Chromium 브라우저에서 제품 검색·종류 필터·검색 초기화 확인
- 상세 탭과 방향키 전환 확인
- 제품 등록·개봉일 수정·사용 완료·재개·삭제 취소·삭제 확인
- 새로고침 후 개봉일과 완료 상태 복원 확인
- 브랜드 설명 펼치기 확인
- 데스크톱 1440px 화면 및 모바일 390px 화면 캡처 확인
- 390px·375px·320px에서 네 메뉴의 가로 넘침 없음 확인
- 위 검증 중 JavaScript 런타임 오류 없음

검증은 현재 실행 환경의 로컬 프로덕션 빌드에 대해 수행했습니다. 공개 Vercel 배포 결과는 별도 확인이 필요합니다.

## iOS 유리 소재를 참고한 글라스모피즘 적용

흑백 브랜드 톤에 반투명 레이어와 넓은 곡률, 가장자리 하이라이트, 부드러운 그림자를 적용했습니다. `glass.css`가 기존 레이아웃 위에 공통 소재와 컴포넌트 스타일을 제공합니다.

- 상단 헤더와 메뉴: 배경이 비치는 둥근 유리 패널
- 모바일 메뉴: 안전 영역을 고려한 아이콘 포함 플로팅 하단 메뉴
- 홈: 캠페인 이미지 위의 반투명 소개 카드
- 제품 카드·검색창·필터·상세 탭·내 제품·더보기: 공통 유리 표면과 명확한 선택 상태
- 흐림 미지원 브라우저와 투명도 줄이기·대비 높이기 설정에 대한 대체 스타일
- 모바일 하단 메뉴를 흐림 처리된 헤더 밖에 배치하여 고정 위치 유지

현재 환경의 Chromium 프로덕션 빌드에서 1440·1024·768·390·375·320px 네 메뉴 배치와 가로 넘침, 모바일 메뉴 위치를 확인했습니다. 검색·등록·개봉일·사용 완료·아코디언과 네이티브 한글 IME 조합·커서 위치 회귀 검증도 통과했습니다. 실제 iOS Safari 검증은 별도로 필요합니다.
