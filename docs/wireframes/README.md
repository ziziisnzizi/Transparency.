# Transparency. 모바일 와이어프레임

사용자가 제공한 상세 흐름과 현재 웹앱을 기준으로 재구성한 **20개 화면의 구조 설계안**입니다. 회색 영역과 X 표시는 이미지 자리입니다. 버튼·행의 `→ 번호`는 이동할 화면을 가리킵니다.

## 파일

- [전체 보드 PNG](overview.png): 2310 × 4380 px
- [전체 보드 SVG](overview.svg): 도형·텍스트를 포함한 벡터 원본
- [공유·출력용 PDF](wireframes.pdf): A3 가로, 5페이지, 페이지당 4개 화면
- `screens/01.svg` ~ `20.svg`: 개별 화면 벡터, 390 × 844
- `screens/01.png` ~ `20.png`: 개별 화면 이미지, 780 × 1688 (2배 해상도)
- `sheet-01.svg` ~ `sheet-05.svg`: PDF 페이지별 벡터 원본
- `index.html`: 다운로드 링크와 전체 보드 보기
- `print.html`: PDF 인쇄 레이아웃

## 상태 구분

- **구현 기반**: 현재 기능을 바탕으로 재구성한 화면입니다.
- **확장**: 현재 기능과 추가 기획이 함께 포함됩니다.
- **기획**: 아직 앱에서 구현하지 않은 화면입니다.

현재 프로토타입은 로그인 없이 이용하며 제품 기록을 브라우저에 저장합니다. 로그인·계정·AI·근거 원문 연결 등은 추가 개발이 필요합니다. 제품명·성분·수치·날짜·이메일은 예시입니다.

## 수정·재생성

저장소 루트에서 Python 표준 라이브러리만으로 SVG와 HTML을 생성할 수 있습니다.

```sh
python3 scripts/generate-wireframes.py
```

PNG·PDF 내보내기는 Playwright와 Chromium이 필요합니다. 웹앱의 의존성과 별도로 설치할 수 있습니다.

```sh
npm install --prefix /tmp/transparency-export playwright
NODE_PATH=/tmp/transparency-export/node_modules node scripts/export-wireframes.cjs
```

시스템 Chromium이 없으면 설치한 브라우저 경로를 `CHROMIUM_PATH`로 지정하세요. SVG의 글꼴은 Noto Sans KR 또는 시스템 한글 글꼴을 사용합니다. 편집 도구와 글꼴 환경에 따라 텍스트 배치가 달라질 수 있습니다.

## 검증

- 20개 화면 SVG가 정상 XML로 파싱됨
- Chromium에서 20개 화면의 텍스트가 화면 좌우를 넘지 않는지 확인
- 전체 보드, 홈, 제품 상세 이미지를 열어 배치 확인
- PDF 5페이지 및 A3 규격 확인
