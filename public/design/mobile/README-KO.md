# Transparency. 모바일 와이어프레임 + 플로우차트

기준: 2026.11.03 현재 구현 / 모바일 390 × 844 / 26개 화면·상태 + 5개 흐름도.

## Figma에서 편집 가능한 화면 만들기

1. ZIP을 풀고 Figma 데스크톱 앱에서 새 디자인 파일을 엽니다.
2. Plugins → Development → Import plugin from manifest…에서 `figma-plugin/manifest.json`을 선택합니다.
3. Development 목록에서 `Transparency. · 모바일 와이어프레임과 플로우차트`를 실행합니다.
4. `01 · 모바일 와이어프레임`, `02 · 사용자 플로우차트` 두 페이지가 생성됩니다.
5. 파일 메뉴의 `Save local copy…`로 `.fig`를 저장합니다.

이 패키지 자체는 네이티브 `.fig` 파일이 아닙니다. Figma 안에서 실제 프레임과 텍스트·도형을 생성하는 가져오기 도구입니다. 와이어프레임은 편집 가능한 Figma 프레임·텍스트·도형으로, 흐름도는 SVG 벡터로 생성됩니다. Auto Layout과 클릭 가능한 프로토타입 연결은 포함하지 않습니다. 실행할 때 기존 페이지를 바꾸지 않고 새 페이지를 만듭니다.

## 플러그인 없이 가져오기

- `screens/`의 SVG를 Figma 캔버스에 드래그하면 화면별로 가져올 수 있습니다.
- `wireframes-board.svg`는 전체 모바일 화면 보드입니다.
- `flows/`의 SVG는 화면 번호와 연결된 플로우차트입니다.
- Mermaid `.mmd`와 Graphviz `.dot`은 흐름도 내용 수정용 원본입니다.
- PDF는 검토·공유용이며, PNG는 빠른 미리보기용입니다.

## 읽는 법

- M01~M26: 화면·스크롤 위치·입력 상태를 구분한 모바일 와이어프레임입니다. 같은 URL 안의 탭이나 상태도 별도 프레임으로 표시합니다.
- F01~F05: 실제 기능의 이동·조건 분기입니다. 같은 M 번호로 화면과 대조할 수 있습니다.
- 회색 X 영역은 이미지 자리입니다. 제품 사진을 재가공한 자료가 아닙니다.
- 로그인 없이 이용, 외부 카메라 QR로 제품 상세 바로 진입, 내 제품의 통합 목록·인라인 날짜 수정 흐름을 반영했습니다.
- 구매는 상품·배송 정보 입력과 주문 내용 확인까지 구현돼 있으며 실제 결제·주문 접수는 연결돼 있지 않습니다.
- 준비된 리뷰와 직접 작성한 리뷰를 함께 집계합니다. 기록·리뷰는 현재 브라우저, AI 대화·배송 입력은 화면 메모리 범위를 반영했습니다.
- 폰트는 Noto Sans KR입니다. 해당 글꼴을 사용할 수 없으면 설치 또는 Figma 글꼴 사용 설정 후 다시 실행하세요.

- M03 · 제품 탐색 · 기본 목록 — 모바일 세로 카드 목록의 첫 제품 T.1. 아래로 S.1·C.1이 이어지며 별점은 각 제품 리뷰 기준입니다.
- M04 · 제품 탐색 · 검색 결과 없음 — 입력어 ‘레미콘’에 일치하는 제품이 없는 상태. 검색·필터 초기화로 목록을 복구합니다.
- M05 · 제품 상세 · 제품 이미지 — 제품 탐색에서 S.1 선택. 상세 첫 영역이며 아래에 성분·함량 탭과 QR 정보가 이어집니다.
- M06 · 제품 상세 · 제형 이미지 — M05에서 ‘제형 보기’ 선택. 같은 제품·같은 주소에서 대표 이미지가 제형으로 전환됩니다.
- M07 · 성분·함량 · 핵심 성분 — 세럼 S.1 상세에서 성분·함량 영역까지 스크롤. 주요 성분 3개와 각 역할을 확인합니다.
- M08 · 효능·근거 · 연구 범위 — 세럼 S.1 효능·근거 탭. 성분 연구와 공개되지 않은 완제품 결과를 구분합니다.
- M09 · 사용 안내 · 루틴과 주의사항 — 세럼 S.1 사용 안내 탭. 사용 순서·약 0.5 mL·잔량 확인·보관·분리배출 안내입니다.
- M10 · 질문하기 · 입력과 FAQ — 질문하기 초기 상태의 입력·FAQ 구성. 추천 질문 3개와 500자 입력, 아래쪽 FAQ가 이어집니다.
- M11 · 질문하기 · Gemini 답변 — Gemini 연결 성공 상태의 답변 영역. 근거는 실제 정보 탭으로 연결되며 다음 질문 입력란이 아래에 이어집니다.
- M12 · 질문하기 · 제품 자료 답변 — Gemini 미연결 시 제품 자료를 안내한 상태. AI로 표현하지 않으며 다음 질문 입력란이 아래에 이어집니다.
- M13 · 질문하기 · 연결 오류 — 네트워크 연결 실패. 전송한 질문은 대화에 남고 입력란은 비워지며 ‘다시 시도’로 같은 질문을 재요청합니다.
- M14 · 사용자 리뷰 · 낮은 별점부터 — S.1의 리뷰만 별점 낮은 순으로 표시. 준비된 10개 리뷰도 전체 수와 평균 별점에 포함됩니다.
- M15 · 사용자 리뷰 · 작성 검증 — 리뷰 작성 영역까지 스크롤. 3점을 선택하고 ‘좋아요’만 제출하여 내용 길이 오류가 표시된 상태입니다.
- M16 · 내 제품 · 등록 전 — 제품 등록 전. 등록하기는 제품 탐색으로 이동하며 별도의 가입 또는 등록 입력 화면은 없습니다.
- M17 · 내 제품 · 미개봉 — 제품 상세의 ‘내 제품에 추가’를 누르면 즉시 등록. 개봉일이 비어 있으면 미개봉입니다.
- M18 · 내 제품 · 개봉일 입력 — 통합 목록의 개봉일 입력란에서 2026-11-03 입력. 날짜가 있으면 ‘사용 중’으로 표시됩니다.
- M19 · 내 제품 · 사용 완료 — 같은 목록에서 ‘사용 완료’ 실행. 별도 완료 탭 없이 상태와 되돌리기 버튼이 바뀝니다.
- M20 · 내 제품 · 삭제 확인 — ‘등록 삭제’ 클릭 후 브라우저의 기본 확인 대화상자. 운영체제·브라우저에 따라 외형이 달라집니다.
- M21 · 더보기 · 브랜드와 안내 — 더보기의 실제 6개 아코디언. 각 항목은 현재 화면 안에서 열리며 별도 법률·계정 페이지는 없습니다.
- M22 · 더보기 · 개인정보 안내 펼침 — ‘개인정보·기록 관리’ 아코디언을 연 뒤 해당 영역까지 스크롤한 상태입니다.
- M23 · 구매 · 제품 선택과 수량 — 구매 페이지 첫 단계. 하나의 제품을 선택하고 수량 1~99개를 정합니다. 실제 결제는 없습니다.
- M24 · 구매 · 배송 정보 입력 — 배송 정보 영역으로 스크롤. 모바일 1열 입력이며 상세 주소 아래에 배송 요청사항·입력 보관 안내가 이어집니다.

- F01 · 전체 내비게이션 — 홈·제품 탐색·내 제품·더보기와 외부 QR 상세 진입, 구매 화면의 연결을 보여줍니다.
